KEBIJAKAN PRIVASI

DATA MINIMAL • TANPA AKUN

1. Data yang kami proses

URL yang Anda tempel dan file hasil konversi sementara (otomatis dihapus ≤10 menit). Riwayat unduhan tersimpan hanya di browser Anda (localStorage) — tidak dikirim ke server.

2. Log teknis

Server mencatat log teknis agregat (waktu, endpoint, platform, status sukses/gagal) untuk keamanan dan rate-limit. Tidak ada profil pengguna, tidak dijual ke pihak ketiga.

3. Analitik opsional

Jika admin mengaktifkan Umami (privacy-friendly, tanpa cookie pelacakan), kunjungan halaman dihitung anonim. Secara default analitik mati.

4. Pihak ketiga

Ekstraksi menghubungi platform sumber (TikTok, IG, YouTube, dll) dan CDN mereka; unduhan langsung bisa terekspos ke CDN tersebut sebagaimana Anda membukanya sendiri.

EN summary: Minimal data: pasted URLs + temp conversion files (auto-deleted ≤10 min). History stays in your browser. Aggregate technical logs only. Analytics (Umami) is off by default.
